## Anti-AI-Slop — Geoportal Aceh

For all interface, design, layout, copywriting, accessibility, responsive,
navigation, and motion work, follow these rules throughout the entire task.

1. Read `.opencode/skills/antislop/SKILL.md` before starting.
2. Read the relevant specialized skill before making changes:
   - UI: `.opencode/skills/antislop-ui/SKILL.md`
   - Layout: `.opencode/skills/antislop-layout/SKILL.md`
   - Copywriting: `.opencode/skills/antislop-copywriting/SKILL.md`
   - Accessibility: `.opencode/skills/antislop-human/SKILL.md`
   - Responsive: `.opencode/skills/antislop-layoutmobile/SKILL.md`
   - Motion: `.opencode/skills/antislop-motion/SKILL.md`
   - Navigation: `.opencode/skills/antislop-nav/SKILL.md`

3. Apply Anti-AI-Slop DURING planning, design, implementation, and review.
4. Follow the project's `DESIGN.md` as the source of visual direction.
5. Do not use generic layouts, fabricated statistics, fake content,
   decorative elements without purpose, or dead navigation links.
6. Preserve the existing Laravel, React, Leaflet, PostgreSQL/PostGIS,
   Redis, and FastAPI architecture.
7. Inspect existing files and dependencies before changing anything.
8. Do not overwrite unrelated work or delete existing data and configuration.
9. Ask before expanding the scope beyond the task requested.

Before beginning interface work, verify that the design direction is clear.
